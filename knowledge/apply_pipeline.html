Apply Pipeline — End-to-End Job Application Automation

Strategy (per Bang's spec, updated 2026-11-24): 2-phase flow — run (fill + screenshot → STOP for review) → Bang reviews → submit (explicit). PAKAI CV LAMA yang sudah teruji (per-company variant kalau ada, fallback base). CL: isi langsung ke text field (jangan upload PDF).

CL strategy (per Bang's spec 2026-11-24)

  • Function: fill_cover_letter_text(page, cl_text) — cari text field dengan label "Cover Letter", isi langsung dengan CL text (plain, stripped dari markdown)

Submit policy (per Bang's spec 2026-11-24)

  • NEVER auto-submit by default — flow always stops at status='review'
  • Auto-submit hanya aktif jika:
  • --auto-submit flag diberikan ke run command, ATAU
  • auto_submit: true di portals.yml (default: false)

  • submit --slug X butuh --yes flag untuk konfirmasi explicit

Known limitations

  1. LinkedIn guest API tidak expose external Apply URL — butuh cookie secondary account
  2. Greenhouse reCAPTCHA block auto-submit — final Submit click butuh human solve captcha
  3. CL maxLength=255 (Greenhouse custom question) — kalau CL text > 255 chars, akan di-truncate browser. Saat ini fill_cover_letter_text tetap isi full text; Bang perlu konfirmasi: truncate / skip / cari field lain (TODO list)
  4. Re-fill saat submit — state form hilang antar session, jadi submit phase re-fill lagi sebelum click Submit. Untuk form dengan captcha, captcha mungkin muncul di phase 1 (screenshot) tapi perlu solve di phase 2 (manual).

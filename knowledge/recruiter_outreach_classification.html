Recruiter Outreach Classification System

Purpose: Standardize how we evaluate and respond to inbound recruiter approaches. Each outreach gets classified across 8 dimensions, scored 1-5 each, then mapped to a response strategy.

📊 Classification Dimensions

1. Recruiter Type (1-5)

Score Type Description
5 Founder/C-level directly CEO/CTO/VP personally reaches out — highest signal
4 In-house recruiter Works at the company directly — full context, fast decisions
3 Headhunter/Independent Specialized independent recruiter — vetted but middleman
2 Agency recruiter (large) Big staffing agency (Robert Half, Hays, etc.) — volume-based
1 Unknown/Cold outreach LinkedIn connection request with brief message — least vetted

2. Opportunity Detail Level (1-5)

Score Level What's provided
5 Detailed Full JD + company name + comp range + tech stack + team size
4 Moderate Role title + company name + brief description
3 Minimal Role title + brief project/client description
2 Vague Just "would you be open to hearing more?" with minimal context
1 Spam-like Generic template, no personalization

3. Seniority Match (1-5)

Score Match Example
5 Exact match Senior SDET (Noorman: 10 yrs, former Test Lead)
4 Stretch up Staff/Principal SDET (growth opportunity)
3 Adjacent level QA Lead → IC SDET (lateral move)
2 Stretch down Mid SDET (might be under-level)
1 Mismatch Junior role, or totally different track (e.g. PM role)

4. Domain Fit (1-5)

Score Match Noorman's domain vs client domain
5 Direct match Fintech/banking/crypto (GoPay, Bank Indonesia, Jenius) or streaming (Vidio)
4 Strong adjacent E-commerce, SaaS, regulated industry, mobile-first consumer apps
3 Tangential MLM/direct selling, EdTech, gaming — transferable skills
2 Weak adjacent Healthcare, automotive, B2B enterprise — partial transfer
1 Unrelated Bio-tech, hardware, government, defense — minimal transfer

5. Work Mode (1-5)

Score Mode Description
5 Remote-first Fully remote, timezone flexibility
4 Hybrid (Indonesia) Hybrid with Jakarta office (or near)
3 Hybrid (specific city) Hybrid in specific foreign city (relocation needed)
2 On-site (Indonesia) On-site in Jakarta (commute OK)
1 On-site (foreign) On-site in foreign country (heavy relocation)

6. Location/Visa Feasibility (1-5)

Score Situation Notes
5 Indonesia-based No visa needed, Noorman in Jakarta
4 Visa-sponsored Company sponsors visa (Spain Digital Nomad, NL HSM, etc.)
3 Contractor-friendly B2B model, work from anywhere (Bonapolia pattern)
2 Visa-required (hard) Must already have right to work (Japan residency, Finland residency)
1 Unknown/Unclear Need to ask, may be blocker

7. Compensation Tier (1-5)

Score Tier Range
5 US/Global remote USD 80-150K/year (top tier)
4 EU/UK/Singapore EUR/GBP 50-80K/year, or SGD 7-12K/month
3 Regional SEA USD 4-8K/month
2 Indonesia market (unicorn) IDR 35-65M/month
1 Indonesia market (mid) IDR 20-35M/month
* Unknown Need to ask — score 3 (neutral)

8. Urgency/Time-to-Response (1-5)

Score Urgency Signal
5 Same-day response expected "Available for call tomorrow"
4 Within 24-48 hours Standard recruiter follow-up
3 Standard (within week) No specific timeline mentioned
2 Slow burn "Keeping you in mind for future"
1 No urgency Generic cold outreach

🎯 Response Strategy Matrix

Total score = sum of all 8 dimensions (max 40)

Total Score Strategy Reply Template
32-40 A. Strong fit + clear info Reply YES immediately + send CV + propose 3 time slots for call
24-31 B. Strong fit + minimal info Reply YES + ask 2-3 clarifying questions + propose call (send CV after answers)
16-23 C. Worth exploring Reply YES + ask clarifying questions BEFORE sending CV
8-15 D. Weak fit Reply politely asking for more info, don't commit
<8 E. Decline Polite decline + keep door open for future

📋 Standard Clarifying Questions (use for Strategy B/C)

When info is minimal, ask these (pick 2-3 most relevant):

  1. Company name — "Could you share the company name so I can research them?"
  2. Full JD — "Is there a full job description you could share?"
  3. Compensation range — "What's the typical compensation range for this role?"
  4. Visa/work authorization — "Does this role require existing work authorization, or is visa sponsorship available?"
  5. Timezone expectations — "What timezone overlap is expected for the remote role?"
  6. Team size — "How large is the QA team I'd be joining/leading?"
  7. Tech stack — "What's the primary tech stack for test automation?"
  8. Start date — "What's the expected start date?"

knowledge/apply_tracker.csv  ← Add entry with status=drafting

🔄 Workflow

  1. Receive outreach → save raw message to Profile/research/<recruiter>_outreach_classification.md
  2. Research recruiter (if LinkedIn profile provided, try WebFetch; if name only, WebSearch)
  3. Classify across 8 dimensions → calculate total score
  4. Determine response strategy (A/B/C/D/E)
  5. Generate reply draft with 3 options based on strategy
  6. Add to tracker with platform=referral, status=drafting
  7. Commit + push (auto-sync to public site reports)

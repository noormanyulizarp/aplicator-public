Apply Pipeline — End-to-End Job Application Automation

Strategy (per Bang's spec): scrape with secondary LinkedIn account → analyze ATS page → generate CV/CL → fill form + screenshot → conditional submit (if safe) → update tracker. Use primary LinkedIn account only after sandbox proves reliable.

LinkedIn strategy (Bang's two-account setup)

  • Secondary account — used for scanning, redirect detection, job analysis. Cookie saved in .li_session.json (gitignored). Blocked OK — just make a new account.
  • Primary account — reserved for Easy Apply + recruiter messages. Cookie saved in .li_session_primary.json (gitignored, set up later). Never burn this.

# Run on top 5 from latest enriched leads
python scripts/apply_pipeline.py run --top 5 --min-score 80

# Dry-run (fill + screenshot, NO submit — default for unsafe portals)
python scripts/apply_pipeline.py run --job-url <URL> --dry-run

Fit score thresholds (per portals.yml)

  • ≥80 → auto-apply candidate (will submit if portal is safe)
  • 60-79 → analyze-only (fill + screenshot, manual review)
  • 50-59 → log + skip
  • <50 → drop from leads

Submit policy

  • Safe portals (auto-submit if score ≥ threshold): Lever, Ashby, Breezy.hr
  • Unsafe portals (always require Bang's review): Greenhouse (reCAPTCHA), Workday, LinkedIn Easy Apply, Custom
  • For unsafe portals, pipeline stops after fill+screenshot. Bang reviews screenshots in applications/{slug}/screenshots/ and clicks Submit manually.

Known limitations (sandbox reality)

  1. LinkedIn guest API does NOT expose external Apply URL — only the JD. To detect the redirect URL for non-Easy-Apply jobs, you need a logged-in cookie.
  2. Greenhouse auto-submit is blocked by reCAPTCHA — even with valid cookie, the final Submit click needs human captcha solve.
  3. Rate limiting: LinkedIn guest API returns 429 after ~6-8 requests in quick succession. The scanner sleeps 1.2-1.5s between requests to be gentle.
  4. Custom questions (Greenhouse question_XXXXX fields) are dynamically detected and filled from portals.yml apply.* defaults; verify before submit.

ATS Keywords — Per Role

ATS (Applicant Tracking Systems) parse your CV for keyword matches against the JD. Below: high-frequency keywords per role to weave into your CV (when truthful).

How to use

  • Don't stuff keywords — ATS also penalize obvious stuffing.
  • Match phrasing from the JD: if JD says "REST APIs", write "REST APIs" not "RESTful services".
  • Use both spelled-out and acronym forms: "Continuous Integration (CI)".
  • For tools: write the brand name exactly (e.g. "Playwright", not "Playwright JS").

Nice-to-have: - Kafka, RabbitMQ, SQS, event-driven architecture - Elasticsearch, OpenSearch - Terraform, Pulumi, Infrastructure as Code - Spring Boot, Django, FastAPI, Express - TDD, BDD, integration testing, unit testing - Observability: Grafana, Prometheus, Datadog, OpenTelemetry - Domain-Driven Design (DDD), Clean Architecture

AI Engineer

Nice-to-have: - Multi-agent orchestration, function calling, tool use - Inference optimization: quantization, distillation, ONNX - MLflow, Weights & Biases, experiment tracking - Distributed training: Ray, DeepSpeed - Vector search: ANN, HNSW, FAISS - Evaluation frameworks: Ragas, DeepEval, Promptfoo - Embedding models: OpenAI ada, BGE, GTE

QA Engineer

SDET

Must-have: - Test automation, automation framework, automation infrastructure - Programming: Python, Java, JavaScript/TypeScript - Selenium, Playwright, Cypress, Appium - TestNG, JUnit, PyTest, Jest, Mocha - CI/CD: Jenkins, GitHub Actions, GitLab CI, ArgoCD - Docker, Kubernetes - API automation: RestAssured, gRPC testing - BDD: Cucumber, Behave, SpecFlow
